# Images du mode Silhouette

Dépose ici une image par combattant (PNG à fond transparent conseillé, WebP ou JPG acceptés).
Le nom du fichier = nom du combattant en minuscules, sans accents, espaces ni ponctuation.
Le nom anglais marche aussi (colonne de droite).

Ce dossier est ignoré par git : tes images restent sur ta machine.
Tu n'es pas obligé de tout remplir, seuls les combattants avec une image tomberont.

Une fois les images ajoutées, recharge la page.
